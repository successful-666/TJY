# 参考文档

> **本目录的实体内容不入库。**
>
> 原因：约 **583 MB**（含 3D 模型、固件更新程序、厂商完整示例工程），

| 文件 / 目录 | 内容 | 用途 |

| `主控.pdf` | 主控板原理图（STM32F407VET6） | 核对引脚分配、以太网/CAN/485 硬件连接 |

| `DM3519/` | 达妙 DM3519 协议示例代码 | CAN 行走电机 |
| `STM32F407_串口通讯__位置模式/` | ZDT 官方 Y42 位置模式例程 | Emm_V5 协议参考 |

## 各项资料的来源

**Y42（张大头闭环步进）**

官方资料随货提供，也可向厂商索取：

- 淘宝店铺：<https://zhangdatou.taobao.com>
- 技术支持博客：<https://blog.csdn.net/zhangdatou666>
- 技术交流群：262438510

需要的关键文档：

- 《ZDT Y42 第二代闭环步进电机使用说明 V1.1》—— **通信协议以这份为准**
- 《ZDT 闭环步进电机 MODBUS 协议使用说明》
- STM32F407 / STM32F103 / TI MSPM0G3507 例程

> 注意：Y42 有 **Emm 固件**和 **X 固件**两种版本，部分命令和数值含义不同。
> 本工程使用的电机是 **Emm 固件**，代码里的换算公式按 Emm 实现。

**DM3519（达妙）**

电机协议与上位机软件由达妙官方提供。

**主控板 / 电源板原理图**

本板为自制板（立创 EDA 绘制），原理图源文件请联系硬件负责人获取。

## 与本工程代码的对应关系

查阅这些资料时，通常是为了核对下面几件事：

| 要确认什么 | 看哪里 | 代码里的对应位置 |
|---|---|---|
| 引脚分配是否与原理图一致 | `主控.pdf` | `.ioc` 与 `code/Core/Src/*.c` |
| Y42 协议字段、数值换算 | Y42 使用说明 5.5 / 5.3 章 | `code/Device/y42.h` |
| DM3519 帧格式 | 达妙协议文档 | `code/Device/dm3519.c` |
| 485 方向脚、终端电阻 | `主控.pdf` 隔离式 485 部分 | `code/BSP/bsp_uart.c` |
